# TableFillingTool · 随聊填表

独立 Windows 桌面工具：导入联系人表格，打开企业微信联系人，用置顶浮窗跟随当前独立聊天窗口填写。表格、右侧填写卡片和浮窗共用本地保存的数据。不需要学员管理平台账号，不发送消息、不修改企微备注。

## 启动

需要 Python 3.10+。首次准备环境：

```powershell
python -m pip install -r requirements.txt
python main.py
```

依赖已安装时直接双击 `start.bat`。当前验证环境为 Windows、Python 3.14.7、PySide6 6.11.2、openpyxl 3.1.5。工具不自动安装依赖。

本地数据默认保存在 Qt 的本工具专用应用目录（Windows 通常为 `%LOCALAPPDATA%\LocalTools\TableFillingTool\tables.sqlite3`），与 StudentManagement 完全独立。可用 `python main.py --data-dir "D:\MyTableData"` 指定其他目录；同一目录同时仅允许一个工具实例。备份本地工作区请先关闭工具，再复制该数据目录；Excel/CSV 导出只包含表格内容，不包含字段类型与联系人配置。

## 填写流程

1. 点击「导入表格」选择 `.xlsx` 或 `.csv`，第一行为字段名；XLSX 的每张工作表分别导入。每次导入创建新表，不覆盖已有表或原文件。同名表自动增加后缀。
2. 打开「联系人设置」，核对姓名列、可选的联系人备注列和前缀。备注非空时直接使用备注；否则搜索「前缀 + 姓名」，前缀直接拼接，需要空格时请写在备注中。各表配置独立保存。
3. 选择记录，点击「打开企微联系人」或按 F8。需先登录企业微信，并保留一个主窗口。工具搜索后用 Ctrl+O 打开独立聊天窗、核对标题，可选择保留或关闭该窗口。操作期间请暂时不要操作鼠标键盘；焦点或进程变化即停止。不会在聊天输入区发送内容。
4. 点击「聊天跟随浮窗」。默认按当前前台的企业微信独立聊天窗口自动切换填写对象，优先用备注/前缀识别，唯一姓名兜底。重名时限定表格；仍重名时需填写唯一备注，不会随意选人。切换到工具填写时保留上一次已匹配记录。主表切换不改变浮窗身份。
5. 在主表双击编辑，或在右侧/浮窗填写。文本停止输入约 450ms 后保存；切换记录、切换表格、导出和关闭前也会保存。失败保留输入并阻止切换，修复目录权限/磁盘问题后点击「重试保存」。浮窗可取消置顶，通过系统标题栏移动；也可用「使用主表所选记录」转为手动填写，重新勾选自动跟随即可恢复。
6. 「导出当前表」将当前表全部记录另存为 XLSX 或 UTF-8 CSV，不受搜索、排序或表头拖动影响。导出按原始字段与记录顺序；保存失败不会破坏目标已有文件。若要保留原文件，请选择不同名称。

可从空白表开始，也可点击「先体验虚构示例」。支持添加行、添加文本/多行/下拉/日期字段；日期按 `YYYY-MM-DD` 填写或留空清除。右键表格可确认删除选中行；此操作不可撤销，原导入文件不受影响。列宽可拖动，点击表头打开筛选与排序。在主表区域按住 Shift 并滚动鼠标滚轮可左右滑动，普通滚轮保持上下滚动。

在「我的表格」列表中右键某张表，点击「删除此表格…」，确认后删除该表及其记录；只影响本工具中的副本，原始 Excel/CSV 不会改变。删除不可撤销，未保存内容写入失败时会阻止删除。

## 筛选与批量验证联系人

点击任意表头（或 `Ctrl+Shift+L` 筛选当前列），可升序/降序、按选项多选（包括空白），或按包含、等于、为空、不为空筛选。选项支持空格分隔多个关键词搜索，以及只全选/取消当前搜索结果；多列条件同时生效。可以重置单列，或点击表格底部「清除筛选」清除搜索与列条件。

筛选列表参考 StudentManagement 画像模块：编辑后整批结果保持可见，不符合条件的行会有提示和淡琥珀色背景（选中时保留选中样式）；排序不重算。点击搜索框旁的「重新筛选」或改变搜索/列条件时重新计算，原记录被排除后优先选择原顺序中的下一条。添加字段也会重新计算，筛选中的新行在重新筛选前不自动进入列表。

在顶部「导入表格」右侧点击「验证联系人」，分别选择搜索字段和可选的结果字段。前缀默认空，搜索词为「前缀 + 搜索字段值」；默认包含匹配，可改为完整匹配（忽略大小写、空白、全半角和已知企微标题后缀）。结果字段只能选择能写入“是”的文本/多行字段或含“是”的选项字段，且不能与搜索字段相同。未指定结果字段时只查看结果，不写回单元格。

验证只处理当前表搜索/筛选仍然匹配的记录，排除编辑后已不符合条件的保留行；零匹配不会回退全表。空搜索值和当前表内重复搜索词列为待确认。只有确认成功才向指定字段写入“是”，未找到、待确认和失败均保留原值；记录或字段在验证期间变化也不会覆盖。每轮显示搜索词、企微标题、结果和说明，同表同字段结构下关闭后再打开保留本轮结果，重启后不保留验证日志。

开始后请勿操作鼠标键盘。F11 或「暂停」在当前联系人结束后暂停，「继续验证」或 F11 恢复，「结束本轮」保留已处理结果并停止剩余记录；关闭运行中的窗口会先请求结束，结束后再关闭。未找到、标题不匹配或操作/写入失败均不会自动暂停，保留原值并继续验证下一条；只有手动请求才暂停。已确认的独立聊天窗会关闭，验证期间暂停填写浮窗的自动跟随。F11 被其他程序占用时不启动，请先结束该程序的自动化任务。导出仍使用当前表全部行、原始顺序。

主窗口顶部依次提供导入、验证联系人、导出和「聊天跟随浮窗」，右侧填写区集中显示当前联系人及「联系人设置」。联系人名称旁显示保存状态，失败时保留输入并在附近显示重试；键盘切换到下方字段时会自动滚动。空表可直接新增首行，无搜索结果时可一键清除搜索。浮窗用文字及颜色区分等待、匹配、歧义、错误和手动模式。界面规则见[桌面界面约定](docs/ui-design.md)。

## 格式与环境边界

- 面向名单/填写数据的值表，不是 Excel 原格式编辑器：不保留原文件的样式、合并单元格、图表、宏或公式计算。公式表达式按普通文本导入和导出，不执行；XLSX 数字格式为纯零占位（如 `00000`）时保留前导零。
- CSV 支持 UTF-8/GB18030、逗号/分号/制表符分隔；CSV 中以 `= + - @` 开头的单元格导出时加单引号，避免 Office 自动执行公式。需要原样保留这类文本时优先使用 XLSX。
- 文件上限 50 MB，每张表最多 50,000 条记录和 200 列，单元格最多 32,000 字。旧版 `.xls` 请先另存为 `.xlsx`。空/重名表头会生成独立名称；不要依赖原工作簿格式或公式参与计算。
- 联系人打开和自动跟随需要 Windows 版企业微信（WXWork.exe/WeCom.exe），主窗口标题为「企业微信」或「WeCom」，并保留默认 Ctrl+F/Ctrl+O/Ctrl+W 快捷键。其他平台可填写及导入导出，但不支持企微操作。
- 同名或多个主窗口会阻止自动操作；关闭联系人验证时只完成搜索，结果需人工核对。不读取聊天消息内容，不自动解析回复。真实企微版本仍需在指定测试联系人上验收。
- StudentManagement 仅作代码参考；新工具不导入其 Python 包，不访问其数据库、登录缓存或业务目录。

## 快捷键与验证

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+O | 导入 |
| Ctrl+N | 新建表格 |
| Ctrl+S | 立即保存填写内容 |
| Ctrl+Shift+S | 导出当前表 |
| Ctrl+Shift+F | 打开聊天跟随浮窗 |
| F8 | 打开所选联系人 |
| Esc（表格单元格内） | 放弃该单元格尚未保存的编辑 |
