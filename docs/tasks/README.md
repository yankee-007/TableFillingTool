# 活动任务

当前无已登记活动任务。后续达到 adaptive 跟踪条件时创建记录；已完成任务保留原路径，不在活动表中占行。

本导航当前采用 TASK_TRACKING_POLICY=adaptive，与项目策略一致。若以后明确改为 disabled，不创建或更新任务/活动表，保留既有记录并说明持续恢复能力下降；always 时为所有实际任务记录，adaptive 时按任务协议判断。

索引只表示当前版本可见的任务，不是跨分支实时调度表。任务文件记录上次核验的快照，接手时与实际代码和 Git 核对。

task-worktree 下任务记录通常先存在各自分支，main 的空表不能证明其他工作区无活动任务；定位已有任务还需按需核对 Git 分支/worktree。集成分支不维护开发占用标志，集成操作仍须串行协调；本表不授予写入权。

新任务的标识、字段、状态和交接规则见 [任务协议](../agent/workflow.md)。任务完成后从活动表移除，默认保留原文件路径。不要登记模板示例或虚构任务。

活动表不保留 done/cancelled 行；收尾先更新 Task，再删行并核对同一 ID 不在活动表。只把行的状态改为 done 不算完成索引清理，历史链接可另放非活动章节。
