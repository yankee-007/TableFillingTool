# 当前架构

## 系统边界与模块

独立 Python/PySide6 Qt Widgets 桌面应用，没有 Web 服务。`main.py` 配置本工具的应用身份、独立目录、QLockFile 和 Store/Workspace/MainWindow。

- `data.py`：Column/Record/Sheet 稳定 ID；SQLite 存储表定义、配置和记录。
- `service.py`：唯一共享写入入口，校验身份/日期/长度，事务成功后才更新内存及发出通知。
- `files.py`：XLSX/CSV 值表转换和原子导出，文件作业通过 QThread 与主界面解耦。
- `models.py`：虚拟表格模型与显示筛选/排序，写入使用稳定 ID。
- `filtering.py`、`filter_dialog.py`：画像式选项/条件筛选及自然排序；显示集合冻结，验证范围剔除实时不匹配行。
- `verification.py`、`verification_dialog.py`：验证任务/匹配决策、F11 暂停、逐条异步验证及结果写入；与源项目无运行依赖。
- `ui.py`：主窗口、表格编辑委托、稳定字段表单、配置对话框、独立置顶跟随窗。
- `matching.py`：备注/前缀优先、唯一姓名兜底、汉字/英文名称边界检查。
- `wecom.py`：真实进程/前台 HWND 检查、独立联系人窗口搜索验证；不含发送代码。
- `fonts.py`、`theme.py`：系统字体、浅色语义 token 和状态样式，离屏预览显式加载系统字体。
- `icons.py`、`widgets.py`：本地 SVG 图标、保留完整可访问文本的长标题省略、带箭头的原生下拉控件、表格空状态；不改变保存格式或企微协议。界面规则见 [桌面界面约定](ui-design.md)。

## 关键数据流与调用关系

导入文件只读解析 → 多张 Sheet/Record → SQLite 原子导入 → Qt 表格与填写卡片。修改 → 表/记录/字段 ID 校验 → SQLite 事务 → 内存和 cellsChanged → 主表/卡片/浮窗更新；字段布局未变化时不重建表单。文本输入延迟约 450ms 合并，切换、导出及关闭前 flush；失败保留原 ID 与输入，拒绝切换。

浮窗每 500ms 只读检查前台窗口 → 验证为 WXWork.exe/WeCom.exe → 按配置范围匹配 → 唯一记录才绑定；离开企微到填写窗时保持上次记录。多匹配/不匹配清除可编辑对象，保存失败则保护旧对象。主表选择不驱动浮窗，除非显式选择手动模式。

打开联系人是显式操作：冻结查询与选项 → 保留剪贴板副本 → 后台搜索（Ctrl+F、粘贴、Enter）→ Ctrl+O → 同进程/标题核对 → 可选 Ctrl+W；每步检查焦点，粘贴前检查查询未变化；结束时仅在剪贴板仍属本操作时恢复。没有在聊天输入区粘贴消息或发送的路径。

导出先保存输入并复制当前 Sheet 快照 → 后台生成临时文件 → 原子替换用户选定目标；不是对原导入文件的实时写回。

列筛选以字段 ID 保存内存条件，应用时冻结命中记录 ID；值变化仅刷新显示与过期标记，排序只重排，显式重新筛选才重算。批量验证取可见且仍符合条件的行（空集保持为空），导出保留既有全表语义。筛选及验证日志不新增数据库表或迁移。

批量验证在 GUI 线程快照搜索/结果字段、原字段值、前缀与匹配方式 → 后台逐条复用企微进程/焦点/剪贴板检查读取独立聊天标题 → GUI 线程仅对确认结果通过 Workspace 写“是”。写入前检查记录身份、搜索原值和结果原值；失败不覆盖。剪贴板在 GUI 线程备份/暂存，仅仍是本次查询时恢复；工作线程不访问 Qt 剪贴板或数据库。暂停/结束在当前联系人完成后生效；全局 F11 独立注册，不替换源程序的热键；模态验证阻止表切换并暂时关闭浮窗跟随，异常或歧义在下一条前暂停。

## 状态、持久化与外部依赖

专用 `tables.sqlite3` 保存 metadata/schema_version、sheets（列定义和联系人配置 JSON）与 records（稳定 ID、位置和单元格 JSON），外键保护表关联。当前 schema_version=1，无源项目数据库迁移。程序通过 QLockFile 限制同一数据目录一个写入实例。导出单元格为文本，CSV 保护公式前缀；XLSX/CSV 导出不携带填写字段类型和联系人配置，完整工作区备份需关闭后复制数据目录。

运行依赖只有 PySide6/openpyxl 和 Python 标准库；Windows API 经 ctypes 使用，不需要源项目、平台账号或网络服务。Git origin 为用户指定的 `yankee-007/TableFillingTool`，集成分支 main。没有自动化服务、部署或发送能力。
